# Konsist boundary whitelist — architecture-gate exceptions (Konsist rule K1)
#
# Lists currently-known, pre-existing cross-feature imports that are allowed to
# pass the architecture gate while their migration is pending. Format: one entry
# per line, "<source-feature>→<target-feature>" (U+2192 arrow), where each name is
# a `:features:<name>` module directory. Blank lines and lines starting with '#'
# are ignored; surrounding whitespace is trimmed.
#
# Entries are deleted here as each cross-feature edge is removed (see epic
# android_super_app_template, Phase 2 Task 11 and Phase 3 Task 12). Deleting an
# entry and then reintroducing the same import will correctly fail the gate.
#

# module and dissolved `features/home`, so all 5 rows are gone: `home→{myWallet,
# transactions,scanner,trends,settings}` no longer exist. `:shell`'s remaining
# dependency on those features is Host privilege (Konsist K6), not a K1 entry.
